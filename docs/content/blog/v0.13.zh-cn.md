Hextra v0.13.0 带来了全新设计的命令面板搜索体验、带灯箱的图库短代码、可折叠提示框、远程图标包，以及改进的 Jupyter 笔记本渲染，同时包含搜索可靠性改进和错误修复。

<!--more-->

## 升级指南

对大多数站点而言没有破坏性变更。使用 [Hugo Modules](https://gohugo.io/hugo-modules/use-modules/) 更新：

```bash
hugo mod get -u github.com/imfing/hextra
```

如果您使用 CSS 自定义了搜索界面，请注意内联搜索框已被对话框取代：`hextra-search-wrapper` 类已移除，同时提供了 `hextra-search-trigger` 和 `hextra-search-dialog` 等新的样式钩子。完整列表请参阅[自定义 CSS 文档]({{% relref "docs/advanced/customization" %}})。

## 亮点

- 命令面板式搜索对话框，支持键盘快捷键
- 图库短代码，提供 PhotoSwipe 灯箱以及网格、轮播和马赛克布局
- 可折叠提示框，支持自定义标题，兼容 Obsidian callouts
- 远程图标包：Lucide、Tabler Icons 和 Simple Icons
- 改进的 Jupyter 笔记本渲染，支持 In/Out 提示符和更多输出类型
- 自定义页面区块 partial，可在页面正文前后注入内容
- 搜索索引指纹化和更简洁的搜索结果

## 新功能

### 命令面板搜索

<!-- TODO: screenshot -->
<!-- ![Command palette search dialog](https://github.com/user-attachments/assets/TODO) -->

内联搜索框已重新设计为命令面板式对话框，类似于主流文档工具中的搜索体验。在任意位置按 <kbd>⌘</kbd>+<kbd>K</kbd>（或 <kbd>Ctrl</kbd>+<kbd>K</kbd>）或 <kbd>/</kbd> 即可打开。

对话框为搜索结果提供面包屑标签、键盘导航以及流畅的打开/关闭动画。导航栏触发按钮在移动端会折叠为仅图标按钮，也可以通过在搜索菜单项上设置 `params.icon`，在桌面端启用仅图标触发按钮：

```yaml {filename="hugo.yaml"}
menu:
  main:
    - name: Search
      weight: 5
      params:
        type: search
        icon: search
```

搜索结果现在也更加简洁：摘要中的 HTML 标签会被移除，标题锚点中的内联标记得到正确处理，并且搜索数据文件在生产环境中会被指纹化，部署后索引更新可立即生效。

### 图库短代码

新的 [`gallery` 短代码]({{% relref "docs/guide/shortcodes/gallery" %}})用于展示一组图片，提供交互式 [PhotoSwipe](https://photoswipe.com/) 灯箱，包括全屏查看、上一张/下一张导航、图片说明和键盘支持。

```markdown
{{</* gallery */>}}
  {{</* gallery-item src="https://picsum.photos/id/1015/1600/1200" thumb="https://picsum.photos/id/1015/800/600" width="1600" height="1200" caption="River valley" */>}}
  {{</* gallery-item src="https://picsum.photos/id/1018/1600/1200" thumb="https://picsum.photos/id/1018/800/600" width="1600" height="1200" caption="Mountain lake" */>}}
  {{</* gallery-item src="https://picsum.photos/id/1019/1600/1200" thumb="https://picsum.photos/id/1019/800/600" width="1600" height="1200" caption="Forest trail" */>}}
{{</* /gallery */>}}
```

{{< gallery >}}
  {{< gallery-item src="https://picsum.photos/id/1015/1600/1200" thumb="https://picsum.photos/id/1015/800/600" width="1600" height="1200" caption="River valley" >}}
  {{< gallery-item src="https://picsum.photos/id/1018/1600/1200" thumb="https://picsum.photos/id/1018/800/600" width="1600" height="1200" caption="Mountain lake" >}}
  {{< gallery-item src="https://picsum.photos/id/1019/1600/1200" thumb="https://picsum.photos/id/1019/800/600" width="1600" height="1200" caption="Forest trail" >}}
{{< /gallery >}}

通过 `type` 参数可选择三种布局类型：统一的 `grid` 网格（默认）、可横向滚动的 `carousel` 轮播，以及允许项目跨越多列或多行的 `mosaic` 马赛克布局。图片来源支持本地页面资源包、全局资源、静态文件和远程 URL。

### 可折叠提示框

[提示框]({{% relref "docs/guide/markdown#alerts" %}})现在支持扩展语法，可实现内容折叠和自定义标题。在提示框类型后添加 `+` 或 `-` 使其可折叠，标记后的文字将作为标题。该语法兼容 [Obsidian callouts](https://help.obsidian.md/Editing+and+formatting/Callouts)。

```markdown {filename=Markdown}
> [!TIP]- Are alerts foldable?
> Yes. Foldable alerts hide their content when collapsed.
```

> [!TIP]- Are alerts foldable?
> Yes. Foldable alerts hide their content when collapsed.

### 远程图标包

除内置的 Heroicons 图标集外，[图标]({{% relref "docs/guide/shortcodes/icon" %}})现在可以通过提供者前缀从远程图标包按需加载：

```markdown
{{</* icon "lucide:house" */>}}
{{</* icon "tabler:user" */>}}
{{</* icon "simple:hugo" */>}}
```

支持的提供者包括 [Lucide](https://lucide.dev/icons/)、[Tabler Icons](https://tabler.io/icons) 和 [Simple Icons](https://simpleicons.org/)。图标在构建时获取，可用于 Hextra 中任何接受图标名称的地方，包括卡片、标签页、徽章、提示框和导航栏菜单项。

### 改进的 Jupyter 笔记本渲染

[`jupyter` 短代码]({{% relref "docs/guide/shortcodes/jupyter" %}})得到大幅改进，现在支持错误回溯、stderr 流、SVG、Markdown、LaTeX、JSON、原始单元格、附件、输出元数据以及单元格可见性元数据。通过新的 `prompts` 参数可显示 Jupyter 风格的 `In [N]:`/`Out[N]:` 执行提示符：

```markdown
{{</* jupyter src="notebook.ipynb" prompts=true */>}}
```

### 自定义页面区块

新的[自定义钩子]({{% relref "docs/advanced/customization#custom-page-sections" %}})允许通过在站点中创建以下任意 partial，在每个页面正文前后注入内容：

```
layouts/_partials/custom/page-begin.html
layouts/_partials/custom/content-begin.html
layouts/_partials/custom/content-end.html
layouts/_partials/custom/page-end.html
```

每个 partial 都以当前 Hugo 页面作为上下文。

## 修复

- 页面加载时立即渲染可见的 Mermaid 图表
- 修复偏好减少动态效果时 Mermaid 图表的缩放
- 为 Hugo 数学渲染器选择兼容的 KaTeX CSS
- 侧边栏没有页面条目时，移动端菜单回退到页面树
- 在链接渲染钩子中解析页面相对 Markdown 链接
- 处理搜索中标题片段的内联标记
- 更新 Hugo 语言配置键至最新约定
