Hextra v0.13.0 は、再設計されたコマンドパレット検索体験、ライトボックス付きの新しいギャラリーショートコード、折りたたみ可能なアラート、リモートアイコンパック、改善された Jupyter ノートブックレンダリングに加え、検索の信頼性向上とバグ修正を提供します。

<!--more-->

## アップグレードガイド

ほとんどのサイトで破壊的変更はありません。[Hugo Modules](https://gohugo.io/hugo-modules/use-modules/) を使って更新してください:

```bash
hugo mod get -u github.com/imfing/hextra
```

CSS で検索 UI をカスタマイズしている場合は、インライン検索ボックスがダイアログに置き換えられたことにご注意ください。`hextra-search-wrapper` クラスは削除され、`hextra-search-trigger` や `hextra-search-dialog` などの新しいフックが利用可能になりました。完全なリストは[カスタム CSS ドキュメント]({{% relref "docs/advanced/customization" %}})をご覧ください。

## ハイライト

- キーボードショートカット付きのコマンドパレット検索ダイアログ
- PhotoSwipe ライトボックスとグリッド、カルーセル、モザイクレイアウトを備えたギャラリーショートコード
- Obsidian コールアウト互換の、カスタムタイトル付き折りたたみ可能なアラート
- リモートアイコンパック: Lucide、Tabler Icons、Simple Icons
- In/Out プロンプトとより多くの出力タイプに対応した Jupyter ノートブックレンダリングの改善
- ページ本文の周囲にコンテンツを挿入するカスタムページセクションパーシャル
- 検索インデックスのフィンガープリントとよりクリーンな検索結果

## 新機能

### コマンドパレット検索

<!-- TODO: screenshot -->
<!-- ![Command palette search dialog](https://github.com/user-attachments/assets/TODO) -->

インライン検索ボックスが、人気のドキュメントツールの検索体験に似たコマンドパレットスタイルのダイアログに再設計されました。どこからでも <kbd>⌘</kbd>+<kbd>K</kbd>（または <kbd>Ctrl</kbd>+<kbd>K</kbd>）か <kbd>/</kbd> を押して開けます。

ダイアログは、検索結果のパンくずラベル、キーボードナビゲーション、スムーズな開閉アニメーションを備えています。ナビバーのトリガーはモバイルではアイコンのみのボタンに折りたたまれます。検索メニュー項目に `params.icon` を設定すると、デスクトップでもアイコンのみのトリガーを利用できます:

```yaml {filename="hugo.yaml"}
menu:
  main:
    - name: Search
      weight: 5
      params:
        type: search
        icon: search
```

検索結果もよりクリーンになりました。抜粋から HTML タグが除去され、見出しアンカー内のインラインマークアップが正しく処理されるようになり、本番環境では検索データファイルがフィンガープリントされるため、デプロイ直後からインデックスの更新が反映されます。

### ギャラリーショートコード

<!-- TODO: screenshot -->
<!-- ![Gallery shortcode with lightbox](https://github.com/user-attachments/assets/TODO) -->

新しい [`gallery` ショートコード]({{% relref "docs/guide/shortcodes/gallery" %}})は、インタラクティブな [PhotoSwipe](https://photoswipe.com/) ライトボックス付きで画像のコレクションを表示します。フルスクリーン表示、前へ/次へナビゲーション、キャプション、キーボード操作に対応しています。

```markdown
{{</* gallery */>}}
  {{</* gallery-item src="images/space.jpg" caption="Space" */>}}
  {{</* gallery-item src="https://example.com/river.jpg" width="1600" height="1200" caption="River valley" */>}}
{{</* /gallery */>}}
```

`type` パラメータで 3 種類のレイアウトを利用できます: 均一な `grid`（デフォルト）、水平スクロール可能な `carousel`、アイテムが複数の列や行にまたがることができる `mosaic` レイアウトです。画像ソースとしては、ローカルのページバンドルリソース、グローバルアセット、静的ファイル、リモート URL のすべてがサポートされています。

### 折りたたみ可能なアラート

<!-- TODO: screenshot -->
<!-- ![Foldable alerts](https://github.com/user-attachments/assets/TODO) -->

[アラート]({{% relref "docs/guide/markdown#alerts" %}})が、折りたたみ可能なコンテンツとカスタムタイトルのための拡張構文をサポートしました。アラートタイプの後に `+` または `-` を追加すると折りたたみ可能になり、マーカーの後にテキストを追加するとタイトルを設定できます。この構文は [Obsidian コールアウト](https://help.obsidian.md/Editing+and+formatting/Callouts)と互換性があります。

```markdown {filename=Markdown}
> [!TIP]- Are alerts foldable?
> Yes. Foldable alerts hide their content when collapsed.
```

### リモートアイコンパック

組み込みの Heroicons セットに加え、プロバイダープレフィックスを使ってリモートアイコンパックから[アイコン]({{% relref "docs/guide/shortcodes/icon" %}})をオンデマンドで読み込めるようになりました:

```markdown
{{</* icon "lucide:house" */>}}
{{</* icon "tabler:user" */>}}
{{</* icon "simple:hugo" */>}}
```

サポートされているプロバイダーは [Lucide](https://lucide.dev/icons/)、[Tabler Icons](https://tabler.io/icons)、[Simple Icons](https://simpleicons.org/) です。アイコンはビルド時に取得され、カード、タブ、バッジ、コールアウト、ナビバーメニュー項目など、Hextra がアイコン名を受け付けるあらゆる場所で利用できます。

### Jupyter ノートブックレンダリングの改善

[`jupyter` ショートコード]({{% relref "docs/guide/shortcodes/jupyter" %}})が大幅に改善され、エラートレースバック、stderr ストリーム、SVG、Markdown、LaTeX、JSON、raw セル、添付ファイル、出力メタデータ、セル表示メタデータをサポートするようになりました。新しい `prompts` パラメータで Jupyter スタイルの `In [N]:`/`Out[N]:` 実行プロンプトを表示できます:

```markdown
{{</* jupyter src="notebook.ipynb" prompts=true */>}}
```

### カスタムページセクション

新しい[カスタマイズフック]({{% relref "docs/advanced/customization#custom-page-sections" %}})により、以下のパーシャルをサイトに作成することで、各ページの本文の周囲にコンテンツを挿入できます:

```
layouts/_partials/custom/page-begin.html
layouts/_partials/custom/content-begin.html
layouts/_partials/custom/content-end.html
layouts/_partials/custom/page-end.html
```

各パーシャルは現在の Hugo ページをコンテキストとして受け取ります。

## 修正

- ページ読み込み時に表示されている Mermaid ダイアグラムを即座にレンダリング
- reduced motion 設定時の Mermaid ダイアグラムのスケーリングを修正
- Hugo の math レンダラーに対して互換性のある KaTeX CSS を選択
- サイドバーにページに紐づくエントリがない場合、モバイルメニューでページツリーにフォールバック
- link render hook でのページ相対 Markdown リンクの解決
- 検索での見出しフラグメント内のインラインマークアップの処理
- Hugo の言語設定キーを最新の規約に更新
