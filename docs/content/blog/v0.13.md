Hextra v0.13.0 introduces a redesigned command palette search experience, a new gallery shortcode with lightbox, foldable alerts, remote icon packs, and improved Jupyter notebook rendering, along with search reliability improvements and bug fixes.

<!--more-->

## Upgrade Guide

No breaking changes are expected for most sites. Update using [Hugo Modules](https://gohugo.io/hugo-modules/use-modules/):

```bash
hugo mod get -u github.com/imfing/hextra
```

If you have customized the search UI with CSS, note that the inline search box has been replaced by a dialog: the `hextra-search-wrapper` class is gone, and new hooks such as `hextra-search-trigger` and `hextra-search-dialog` are available. See the [custom CSS documentation]({{% relref "docs/advanced/customization" %}}) for the full list.

## Highlights

- Command palette search dialog with keyboard shortcuts
- Gallery shortcode with PhotoSwipe lightbox and grid, carousel, and mosaic layouts
- Foldable alerts with custom titles, compatible with Obsidian callouts
- Remote icon packs: Lucide, Tabler Icons, and Simple Icons
- Improved Jupyter notebook rendering with In/Out prompts and more output types
- Custom page section partials for injecting content around the page body
- Search index fingerprinting and cleaner search results

## New Features

### Command Palette Search

<!-- TODO: screenshot -->
<!-- ![Command palette search dialog](https://github.com/user-attachments/assets/TODO) -->

The inline search box has been redesigned into a command-palette-style dialog, similar to the search experience in popular documentation tools. Press <kbd>⌘</kbd>+<kbd>K</kbd> (or <kbd>Ctrl</kbd>+<kbd>K</kbd>) or <kbd>/</kbd> anywhere to open it.

The dialog features breadcrumb labels for results, keyboard navigation, and smooth open/close animations. The navbar trigger collapses to an icon-only button on mobile, and you can opt into an icon-only trigger on desktop by setting `params.icon` on the search menu item:

```yaml {filename="hugo.yaml"}
menu:
  main:
    - name: Search
      weight: 5
      params:
        type: search
        icon: search
```

Search results are also cleaner now: HTML tags are stripped from excerpts, inline markup in heading anchors is handled correctly, and the search data file is fingerprinted in production so index updates are picked up immediately after a deploy.

### Gallery Shortcode

<!-- TODO: screenshot -->
<!-- ![Gallery shortcode with lightbox](https://github.com/user-attachments/assets/TODO) -->

The new [`gallery` shortcode]({{% relref "docs/guide/shortcodes/gallery" %}}) displays a collection of images with an interactive [PhotoSwipe](https://photoswipe.com/) lightbox, including full-screen viewing, previous/next navigation, captions, and keyboard support.

```markdown
{{</* gallery */>}}
  {{</* gallery-item src="images/space.jpg" caption="Space" */>}}
  {{</* gallery-item src="https://example.com/river.jpg" width="1600" height="1200" caption="River valley" */>}}
{{</* /gallery */>}}
```

Three layout types are available via the `type` parameter: a uniform `grid` (default), a horizontally scrollable `carousel`, and a `mosaic` layout where items can span multiple columns or rows. Local page bundle resources, global assets, static files, and remote URLs are all supported as image sources.

### Foldable Alerts

<!-- TODO: screenshot -->
<!-- ![Foldable alerts](https://github.com/user-attachments/assets/TODO) -->

[Alerts]({{% relref "docs/guide/markdown#alerts" %}}) now support an extended syntax for collapsible content and custom titles. Add `+` or `-` after the alert type to make it foldable, and text after the marker to set a title. The syntax is compatible with [Obsidian callouts](https://help.obsidian.md/Editing+and+formatting/Callouts).

```markdown {filename=Markdown}
> [!TIP]- Are alerts foldable?
> Yes. Foldable alerts hide their content when collapsed.
```

### Remote Icon Packs

Beyond the built-in Heroicons set, [icons]({{% relref "docs/guide/shortcodes/icon" %}}) can now be loaded on demand from remote icon packs using a provider prefix:

```markdown
{{</* icon "lucide:house" */>}}
{{</* icon "tabler:user" */>}}
{{</* icon "simple:hugo" */>}}
```

Supported providers are [Lucide](https://lucide.dev/icons/), [Tabler Icons](https://tabler.io/icons), and [Simple Icons](https://simpleicons.org/). Icons are fetched at build time and work anywhere Hextra accepts an icon name, including cards, tabs, badges, callouts, and navbar menu items.

### Improved Jupyter Notebook Rendering

The [`jupyter` shortcode]({{% relref "docs/guide/shortcodes/jupyter" %}}) has been substantially improved and now supports error tracebacks, stderr streams, SVG, Markdown, LaTeX, JSON, raw cells, attachments, output metadata, and cell visibility metadata. Jupyter-style `In [N]:`/`Out[N]:` execution prompts can be displayed with the new `prompts` parameter:

```markdown
{{</* jupyter src="notebook.ipynb" prompts=true */>}}
```

### Custom Page Sections

New [customization hooks]({{% relref "docs/advanced/customization#custom-page-sections" %}}) let you inject content around each page's body by creating any of these partials in your site:

```
layouts/_partials/custom/page-begin.html
layouts/_partials/custom/content-begin.html
layouts/_partials/custom/content-end.html
layouts/_partials/custom/page-end.html
```

Each partial receives the current Hugo page as context.
